# Roadmap

> This documentation is currently written in English. Italian translation is planned.

Future ideas for Hytale Server Manager after the first public release:

- Optional `tmux` or `screen` console mode for persistent interactive administration.
- Remote backup targets such as SFTP, rsync, object storage, or NAS shares.
- Proxmox snapshot integration for LXC and VM-based deployments.
- Discord or Telegram alerts for update status, crashes, restarts, and backup results.
- Dedicated English docs folder with full translations of the current Italian documentation.
- Installer dry-run mode to preview actions before modifying the host.
- Uninstall script for clean removal of service files, cron entries, and optional runtime data.
- `systemd` timer alternative to cron for autoupdate scheduling.
